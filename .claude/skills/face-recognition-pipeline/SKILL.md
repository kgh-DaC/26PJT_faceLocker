# 얼굴 인식 파이프라인

## 구조

```
Camera → Detector(YuNet) → 품질검사 → Aligner → Embedder(SFace/ArcFace)
      → Recognizer(갤러리와 코사인 유사도) → Decision(N-of-M 투표) → DoorController/LED/Display
```

각 단계는 `src/facedoor/` 모듈 하나이며 인터페이스 뒤에 구현을 숨긴다. 백엔드를 바꿔도 나머지가 영향받지 않게 하기 위해서다.

## 단계별 지침

**카메라**: OpenCV `VideoCapture`. Windows는 `CAP_DSHOW`, Ubuntu는 `CAP_V4L2`로 분기하고 MJPG 640x480 30fps를 기본으로 한다. 프레임 읽기 실패는 N회 재시도 후 예외로 올려 상위가 문을 닫게 한다(fail-closed).

**검출/품질**: 얼굴 최소 크기, 라플라시안 분산(블러), 평균 밝기 범위를 검사한다. 미달이면 HOLD 상태로 점수 계산을 건너뛴다. 어둡거나 흐린 프레임의 낮은 점수가 정상 사용자를 거부로 오판하는 것도, 노이즈가 우연히 타인과 맞는 것도 막기 위해서다.

**등록**: `scripts/enroll.py --name 홍길동`. 안내 문구로 정면·좌·우·위·아래, 그리고 `--tag` 조건(`normal`, `glasses`, `noglasses`, `mask`, `scarf`, `lowlight`)별로 각 5~10장을 받는다. 임베딩은 L2 정규화 후 `data/gallery/<name>/<tag>_<n>.npy`와 원본 얼굴 crop(`.jpg`)을 함께 저장한다. 원본을 남겨야 모델 교체 시 재임베딩이 가능하다. 등록 직후 자기 자신 점수 분포를 보고 이상치(다른 사람이 섞임)를 제거한다.

**인식**: 입력 임베딩과 사람별 갤러리 임베딩의 코사인 유사도 중 최대값(또는 상위 k 평균)을 그 사람의 점수로 한다. 최고 점수 ≥ 임계값이고 2위와의 격차 ≥ margin이면 후보로 인정한다. 임계값은 `models/calibration.json`의 목표 FAR 값을 쓰며, 없으면 설정 기본값(보수적)으로 간다.

**조건별 강건성(핵심)**
- 조명: 갤러리에 저조도/역광 샘플 포함, 입력에 CLAHE(조도 정규화)는 A/B 평가 후 켠다. 켠다고 항상 좋아지지 않기 때문이다.
- 마스크: 마스크 시 눈 주변 정보만 남아 점수가 떨어진다. 마스크 갤러리 샘플을 별도 태그로 등록하고, 마스크 감지 시 마스크 전용(더 높은 FAR 위험) 임계값을 별도로 보정한다. 마스크용 임계값을 일반보다 낮추려면 반드시 평가 리포트의 해당 조건 FAR을 근거로 한다.
- 안경/목도리: 착용·미착용 샘플을 모두 등록한다. 목도리는 하관 가림이라 마스크와 같은 취급을 한다.
- 위 대응이 부족하면 증강(밝기/감마/가상 마스크·안경)으로 갤러리를 보강하되 합성 샘플은 `synthetic` 태그로 구분한다.

**판정(Decision)**: 최근 M프레임 중 같은 사람이 N회 이상(기본 3/5) 임계값을 넘으면 OPEN. 도중 다른 사람이 섞이거나 Unknown이면 카운터를 리셋한다. OPEN 후에는 쿨다운 동안 재판정하지 않는다. 한 프레임 순간 오탐이 문을 여는 것을 막기 위함이다.

**화면**: 초록 박스=등록자(이름, 점수), 빨강=Unknown, 노랑=HOLD(이유 표시), 우상단에 `DOOR SIGNAL: ON/OFF`와 LED 상태, FPS. `--no-display`에서는 로그만.

**이벤트 로그**: 모든 판정을 `logs/events.csv`에 쓴다. 지표 계산을 이 로그로 재현할 수 있어야 "추후 올바르게 평가되었는지" 판단이 가능하다.

## 위조 방어
사진/영상 재생으로 열릴 수 있다는 점을 README에 명시한다. 기본 구현에는 `Liveness` 인터페이스(기본 no-op)만 두고, 필요 시 눈 깜빡임/IR 카메라/깊이 센서를 붙이게 한다. 이를 숨기지 않는 이유는 이 시스템이 물리 출입 제어이기 때문이다.

## 테스트
합성/저장 이미지로 `pytest`: 등록→인식 왕복, 품질 미달 시 HOLD, 투표 로직(순간 오탐 무시), 임계값 경계. 카메라 없이 `FileCamera`(이미지 폴더/동영상)로 같은 파이프라인을 돌릴 수 있게 한다.
